# Vendored: Superpowers skills

The skill directories in this folder are vendored from
[obra/superpowers](https://github.com/obra/superpowers) (MIT License,
Copyright (c) 2025 Jesse Vincent), commit at time of import.

They provide this project's development methodology: brainstorming →
writing-plans → subagent-driven-development / executing-plans, backed by
TDD, systematic-debugging, git-worktree isolation, and code-review
skills. See `using-superpowers/SKILL.md` for the entry point.

Not modified from upstream except for selection (not every skill in the
source repo was copied — only the ones relevant to building this
product). Re-sync manually from upstream if these fall behind.
