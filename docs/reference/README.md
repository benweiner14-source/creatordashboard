# Reference Material

Source material handed off from outside this repo, kept for when we build the
feature it informs — not specs, not plans, just raw reference to adapt from
later.

- `creator-dashboard-source-skills-export.md` — the actual literal content of
  every Claude Code skill (and supporting Python scripts) that the product
  brief's post-Diagnostic features are built on: Weekly Content Ideas, Recap
  Card, Hook Generator, AI-Writing Cleanup, Thumbnail Maker, Avatar-ify, and
  a Transcript Puller, plus two shelved ideas kept for reference only. These
  are Claude Code skill files — AI agent instructions, not backend app
  code — so adapting them means extracting the domain knowledge (ranking
  logic, style rules, prompt templates, working Python where present) into
  whatever this product's actual backend calls. See the file's own header
  and per-feature "Adaptation note" sections for how each one translates.
